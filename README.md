ADACHI STORE DROPSHIPPING STARTER

1. Open products.js and change STORE.whatsapp to your real WhatsApp number in international format, e.g. 2348012345678.
2. Replace the sample products/prices with products from your supplier.
3. Create a public GitHub repository and upload index.html, style.css, products.js and app.js.
4. GitHub Settings > Pages > Deploy from branch > main > /(root) > Save.
5. Share the generated GitHub Pages address.

This starter sends orders to WhatsApp. It does not falsely claim payment has been completed. Confirm stock, delivery fee and final price before payment.
